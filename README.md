# Бот «КП U-Technology»

Телеграм-бот для партнёра: присылаете КП завода (или своё китайское КП) — получаете
готовое фирменное коммерческое предложение U-Technology в **Excel и PDF**, на нужных
языках, с логотипом, фото товаров, переводом и наценкой.

## Что умеет

* Читает **xlsx, xls, pdf, docx, csv**, а также фото и скриншоты таблиц.
* Своё КП (в формате U-Technology) разбирает **точно и без ИИ** — мгновенно и бесплатно.
* Чужие КП заводов любого вида разбирает ИИ: позиции, параметры, опции (选配),
  фото, все дополнительные колонки, строки доставки.
* Переводит на **русский / 中文 / English** с техническим глоссарием
  (选配 → Опция, 门架 → мачта, 电瓶 → АКБ, 堆垛车 → штабелёр …).
  Модели и обозначения (Q, h3, Ast, SL15, HS CODE) не переводятся.
* Считает цены: наценка общая и по каждой позиции, валюта CNY/USD/RUB/EUR
  по кросс-курсу ЦБ РФ (или свой курс), округление 0,01 / 1 / 10 / 100.
* Кнопками правится всё: позиции, параметры, фото, опции, колонки,
  строки доставки, условия оплаты, срок, гарантия, базис поставки, клиент.
* Отдаёт Excel (как в ваших образцах: голубая шапка, фото в ячейках, объединённое
  примечание, синяя полоса) и PDF на фирменном бланке с колонтитулами.

Файлы называются `UT-ГГГГММДД-NNN_RU.xlsx` / `.pdf`.

## Запуск

1. **Бот.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Ключ OpenAI.** <https://platform.openai.com/api-keys>.
3. **Настройки.**

   ```bash
   cp .env.example .env
   # впишите BOT_TOKEN и OPENAI_API_KEY
   ```

4. **Старт.**

   ```bash
   docker compose up -d --build
   docker compose logs -f
   ```

> **Сервер должен быть вне Китая и России** — OpenAI там недоступен.
> Если сервер всё же там, укажите прокси в `OPENAI_BASE_URL`.

## Запуск на Railway

Railway сам увидит `Dockerfile` (это задано в `railway.json`) и соберёт образ.

1. **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. **Variables** — добавьте переменные (файл `.env` в репозиторий не кладётся):

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от @BotFather |
   | `OPENAI_API_KEY` | ключ OpenAI |
   | `OPENAI_MODEL` | `gpt-5-mini` |
   | `ALLOWED_USER_IDS` | ваш Telegram ID и ID партнёра через запятую |
   | `OPENAI_BASE_URL` | только если нужен прокси |

3. **Volume — обязательно.** Диск Railway очищается при каждом передеплое.
   Без тома после обновления пропадут настройки партнёра, текущее КП, фото и
   счётчик номеров (нумерация начнётся заново).

   **Settings → Volumes → New Volume**, точка монтирования `/app/data`.

4. Порт открывать не нужно: бот работает на long polling, это worker без HTTP.
5. Деплой → **Deploy Logs** → должно появиться `Бот запущен`.
6. Напишите боту **`/diag`** — он покажет, задан ли ключ, какая модель,
   доступен ли Responses API, и сделает тестовый перевод «电动搬运车».
   Если перевод не работает, это видно сразу, без отправки файла.

### Если КП пришло непереведённым

Бот теперь сам предупреждает в чате, когда перевод не выполнен или выполнен
частично. Причина почти всегда одна из трёх — `/diag` покажет, какая:

* `OPENAI_API_KEY: НЕ задан` — добавьте переменную;
* `Responses API: НЕТ` — слишком старая версия `openai`
  (нужен ≥ 1.99, пакет использует `client.responses.parse`);
* ошибка в тестовом переводе — неверный ключ, нет доступа к модели
  или OpenAI недоступен из региона (тогда `OPENAI_BASE_URL` на прокси).

Регион Railway выбирайте любой, кроме азиатского поближе к КНР — OpenAI должен
быть доступен (US/EU подходят).

### Доступ

`ALLOWED_USER_IDS` — Telegram ID через запятую, кому можно пользоваться ботом.
Пусто — можно всем. Если доступа нет, бот ответит «Нет доступа, ваш ID: …» —
этот ID и добавьте в переменную.

### Настройка бренда

`branding/company.toml` — название, цвета, шрифты, префикс номера, контакты для
бланка PDF, сноска. `branding/logo.png` — логотип (уже извлечён из вашего КП).
После правки: `docker compose restart`.

## Проверка без Телеграма

> Папки `examples/` в репозитории нет намеренно: в ней лежат настоящие КП с
> закупочными ценами завода и наценкой — в публичный репозиторий это класть
> нельзя. Для тестов положите в `examples/` файлы `kp_cn.xlsx`, `kp_ru.xlsx`,
> `ex3.xlsx`, `ex4.pdf`, `ex5.pdf`. Самому боту они не нужны.

```bash
pip install -r requirements.txt

# разбор образцов и сборка Excel + PDF в out/
python tests/render_samples.py

# сквозной тест: цены, перевод, кнопки, ввод, отправка файлов
python tests/test_flow.py
```

`test_flow.py` проверяет главное: `kp_cn.xlsx` с наценкой 6 % даёт цены
**3975 / 2915 / 9434 / 8268** и опции **4187; 3127/3339/3551; 10282/10494/10706;
8374/8586** — ровно как в `kp_ru.xlsx`, переведённом вручную.

> PDF собирается через WeasyPrint, которому нужны системные библиотеки Pango.
> В Docker-образе они есть. На Windows их обычно нет — тогда тесты сохраняют
> HTML-вёрстку (её можно открыть браузером), а PDF пропускают.

## Структура

```
bot/
  main.py                запуск polling, команды /start /card /new
  config.py              .env + branding/company.toml
  models.py              модель КП и расчёт цен
  storage.py             data/users/<tg_id>/ (quote.json, prefs.json, photos/)
  service.py             импорт → настройки → перевод → сборка файлов
  handlers.py            файлы, карточка с кнопками, ввод, отправка
  i18n.py                тексты интерфейса RU/中文
  rates.py               курсы ЦБ РФ (кэш 1 ч), номер КП
  parsing/extract.py     чтение файлов + извлечение фото
  parsing/own_template.py разбор своего формата без ИИ
  parsing/ai.py          разбор чужих КП и перевод
  render/labels.py       подписи на ru/zh/en
  render/common.py       общие функции
  render/xlsx.py         фирменный Excel
  render/pdf.py          фирменный PDF
templates/quote.html     шаблон PDF
branding/                company.toml, logo.png
examples/                образцы КП (локально, в репозиторий не коммитятся)
tests/                   render_samples.py, test_flow.py
Dockerfile, docker-compose.yml, railway.json
```

Данные пользователей — в `data/`: `users/<tg_id>/quote.json`, `prefs.json`,
`photos/` и общий `counter.json` с номерами КП. Эта папка монтируется томом и
должна переживать перезапуск — на Railway для неё нужен Volume на `/app/data`.

# 给合作伙伴的简要说明 / Краткая инструкция для партнёра

**U-Technology 报价单机器人**

1. 在 Telegram 中打开机器人，发送 `/start`，选择界面语言（中文 / Русский）。
2. 直接把工厂的报价单发给机器人：Excel、PDF、Word，或表格照片、截图均可。
3. 机器人会自动识别产品、参数、选配、图片和价格，并立即返回
   带 U-Technology 标志的 **Excel 和 PDF** 报价单。
4. 用下方按钮调整：

   * **➕ 加价** —— 统一加价百分比（也可为每个产品单独设置）；
   * **🌐 语言** —— 俄语 / 中文 / 英语，可多选，每种语言各出一份文件；
   * **💱 货币** —— 人民币 / 美元 / 卢布 / 欧元，按俄罗斯央行汇率换算；
   * **🔢 取整** —— 价格取整步长；
   * **✏️ 产品** —— 修改名称、参数、数量、价格、图片、选配；
   * **🧩 列** —— 显示或隐藏任意一列（隐藏设置会记住，下次沿用）；
   * **🚚 运输与条款** —— 贸易条款、付款条件、生产周期、质保、运费行；
   * **👤 客户** —— 填写客户名称。
5. 点击 **📄 生成报价单**，即可收到最终的 Excel 和 PDF 文件。
6. 需要处理新的报价单时，点击 **🆕 新报价单** 或发送 `/new`。

> 文件最大 20 MB（Telegram 限制）。如果图片过大，请先压缩。
